# שומר מאמרים (Article Saver)

תוסף לדפדפן Chrome (Manifest V3) שמאפשר לשמור מאמרים לרשימות, לייצר תקציר AI, לשמור קבצי PDF לתיקייה ולייצא ל-Excel.

## תכונות

- **חלונית צד (Side Panel)** שנפתחת מימין.
- **שמירת מאמרים לרשימות מרובות** (יצירה / עריכה / מחיקה של רשימות).
- שמירה אוטומטית של **כותרת, גוף המאמר ו-URL**.
- **תקציר AI** דרך Google AI Studio (Gemini API) - עם שדה להזנת API key ומודל.
- **שמירת קבצי PDF** בתיקייה שנבחרה על ידי המשתמש.
- **ייצוא ל-Excel** - גיליון "כל המאמרים" + גיליון לכל רשימה.
- אחסון מקומי ב-IndexedDB (פרטיות מלאה - ללא שרת).

## התקנה

1. פתח בדפדפן Chrome: `chrome://extensions`.
2. הפעל את **מצב מפתחים** (Developer mode).
3. לחץ **"טען פרוק"** (Load unpacked) ובחר בתיקייה זו.
4. פתח את החלונית דרך האייקון של התוסף בסרגל הכלים (ניתן להצמיד אותה מימין).

## שימוש

1. **צור רשימה** בקטע "ניהול רשימות".
2. בחר רשימה פעילה, ולחץ **"שמור את המאמר הנוכחי"**.
3. (אופציונלי) בקטע "תקציר AI" הדבק את ה-**API key** מ-Google AI Studio ובחר מודל, סמן "הוסף תקציר AI", וכל שמירה תכלול גם תקציר.
4. ב"הגדרות" אפשר לבחור **תיקייה לשמירת PDF** - כל מאמר שנשמר יישמר גם כקובץ PDF.
5. לחץ **"ייצוא ל-Excel"** כדי לשמור קובץ xlsx עם כל המאמרים.

## מבנה הקבצים

| קובץ | תפקיד |
| --- | --- |
| `manifest.json` | הגדרות התוסף וההרשאות |
| `background.js` | service worker - חילוץ מאמרים וקריאה ל-Gemini API |
| `storage.js` | שכבת IndexedDB (רשימות, מאמרים, הגדרות) |
| `sidepanel.html/css/js` | חלון הצד - ממשק המשתמש |
| `pdf-export.js` | יצירת קבצי PDF (jsPDF) |
| `excel-export.js` | יצירת קובץ Excel (SheetJS) |
| `lib/` | ספריות מקומיות (jsPDF, SheetJS) |
