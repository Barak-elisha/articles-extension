# שומר מאמרים (Article Saver)

תוסף לדפדפן Chrome (Manifest V3, `version 1.0.0`) לשמירת מאמרים לרשימות, הפקת תקציר AI, שיחה עם מודל Gemini על כל מאמר, הערות עשירות וייצוא ל-Excel.

- **פרטיות מלאה** — כל הנתונים נשמרים מקומית ב-IndexedDB בדפדפן, ללא שרת.
- מאגר רשמי: `https://github.com/Barak-elisha/articles-extention.git` (branch `main`).

## תכונות

- **חלונית צד** (Side Panel) שנפתחת מימין, ופתיחה אוטומטית של החלונית בלחיצה על אייקון התוסף.
- **ניהול רשימות** — יצירה, שינוי שם ומחיקה (מחיקה מוחקת גם את מאמרי הרשימה).
- **שמירת מאמר** מהטאב הפעיל — חילוץ כותרת, גוף המאמר ו-URL, כולל שמירה אוטומטית של תקציר AI.
- **שיחה עם AI על כל מאמר** — צ'אט מובנה שמתייחס לגוף המאמר בלבד. השיחה נשמרת ומתווספת ל-Excel.
- **הערות אישיות** לכל מאמר עם עורך עשיר (מודגש, נטוי, רשימות, גודל וצבע טקסט), נשמרות אוטומטית.
- **עריכת הטקסט המלא של המאמר** — ישירות מהחלונית, עם שמירה אוטומטית.
- **מצב חלון מלא** — שלוש עמודות שוות (שליש-שליש-שליש) על מסך שלם: רשימות | תקציר+הערות+שיחה | טקסט מלא.
- **ייצוא ל-Excel** — גיליון "כל המאמרים" + גיליון לכל רשימה, עם טקסט עשיר, קישורים ניתנים ללחיצה, ציטוט APA ועמודת שיחה עם AI.
- **הגדרות AI** — מפתח API ומודל מ-Google AI Studio (ברירת מחדל: `gemini-2.0-flash`).

## התקנה

1. פתח ב-Chrome: `chrome://extensions`.
2. הפעל **מצב מפתחים** (Developer mode).
3. לחץ **"טען פרוק"** (Load unpacked) ובחר בתיקייה זו.
4. החלונית נפתחת בלחיצה על אייקון התוסף בסרגל הכלים.

## שימוש

1. **צור רשימה** בקטע "ניהול רשימות".
2. בחר רשימה פעילה ולחץ **"שמור את המאמר הנוכחי"**.
3. (אופציונלי) בהגדרות → "הגדרות AI" הדבק **API key** מ-Google AI Studio ובחר מודל; יש ללחוץ **שמור מפתח**.
4. לחץ **"ייצוא ל-Excel"** כדי לשמור `מאמרים.xlsx`.

### צפייה וטיפול במאמר

- לחיצה על כותרת מאמר פותחת את פרטיו: **תקציר AI** (+ כפתור "צור מחדש"), **הערות שלי**, **שיחה עם AI**, והטקסט המלא.
- בצד החלונית מתחת לרשימה: **פתח** (מקור במקור) ו-**✕** (מחיקה).
- המאמר הפעיל מודגש בכחול.
- תקציר מוצג ב-Markdown (כותרות, רשימות, קוד, לינקים).

### מצב חלון מלא (⛶)

- כפתור **⛶** פותח כרטיסייה `sidepanel.html?mode=full` באותו חלון.
- שלוש עמודות ברוחב שווה: **הרשימות שלי** | **תקציר AI + הערות + שיחה** | **הטקסט המלא**.
- גובה העמוד נתון לגובה עמודת הרשימות (העמוד מסתיים בסוף הרשימות); הפאנלים בגובה תוכנם, וכשאין מקום מופיעה גלילה פנימית. תיבת הצ'אט נמתחת עד סוף העמוד.

### AI

התוסף מדבר עם Google Gemini (v1beta `generateContent`), עם שני מצבים:

| מצב | הודעה ל-background | תיאור |
| --- | --- | --- |
| תקציר | `GENERATE_SUMMARY` | תקציר מקיף בעברית של גוף המאמר (עד 12,000 תווים נשלחים, עד 2,048 תווי פלט). |
| שיחה | `CHAT_ARTICLE` | שאלות ותשובות על המאמר בלבד; `systemInstruction` מכוון את המודל לענות רק לפי תוכן המאמר, ומועברים 20 ההודעות האחרונות. |

להפעלה יש להזין API key. בתיבת "הוסף תקציר AI" מוגדרת אם כל שמירה כוללת הפקה אוטומטית של תקציר.

### Excel

העמודות בגיליון "כל המאמרים" (ובגיליונות הרשימות):

| עמודה | מקור |
| --- | --- |
| רשימה | שם הרשימה |
| כותרת | כותרת המאמר |
| תקציר AI | `a.summary` (Markdown → טקסט עשיר) |
| הערות | `a.notes` (HTML → runs של מודגש/נטוי/קו תחתון/צבע/גודל) |
| ציטוט APA | `buildApaCitation` — כותרת + תאריך + אתר + URL |
| כתובת אתר | hyperlink פעיל |
| תאריך שמירה | `a.savedAt` |
| שיחה עם AI | `a.chat` בפורמט `אני: …` / `AI: …` |

מימוש ייצוא מורכב:
- `buildExcelBlob` — בניית החוברת עם `xlsx-js-style` (ערכות, גלישת טקסט, רוחבי עמודות, גיליון לכל רשימה).
- `enhanceWorkbook` — שלב עיבוד נוסף עם JSZip: המרת תקציר למריץ rich-text (`inlineStr`), כל עמודת URL ל-hyperlink (עם `_rels/sheet*.xml.rels`), והקפדה על סדר תקני ב-OOXML.
- `isWellFormedWorkbook` — פתיחה מחדש ואימות XML תקין + סדר תגיות ב-`<rPr>`; אם משהו נשבר חוזרים לפלט הגולמי הבטוח של SheetJS.

## ארכיטקטורה

### מבנה הקבצים

| קובץ | תפקיד |
| --- | --- |
| `manifest.json` | הגדרות התוסף, הרשאות וטעינת החלקים |
| `background.js` | service worker — חילוץ המאמר מהטאב הפעיל וקריאות ל-Gemini |
| `storage.js` | שכבת IndexedDB (רשימות, מאמרים, הגדרות) |
| `sidepanel.html/css/js` | ממשק המשתמש של החלונית ומצב החלון המלא |
| `excel-export.js` | ייצוא Excel כולל עיטור rich-text, לינקים ואימות |
| `lib/` | ספריות מקומיות: `jszip.min.js`, `xlsx-js-style.min.js`, `cpexcel.js` |
| `icons/` | סמלי התוסף (16/32/48/128) |

הקלטת הסקריפטים ב-`sidepanel.html` (לפי הסדר!): `jszip` → `cpexcel` → `xlsx-js-style` → `storage` → `excel-export` → `sidepanel`.

### יריד הודעות בין panel ל-background

| type | קלט | פלט |
| --- | --- | --- |
| `EXTRACT_ARTICLE` | — | `{ ok, data: { title, content, url } }` |
| `GENERATE_SUMMARY` | `{ apiKey, content, title, model }` | `{ ok, summary }` |
| `CHAT_ARTICLE` | `{ apiKey, model, title, content, messages }` | `{ ok, text }` |

`extractFromPage` רץ בתוך הטאב (באמצעות `chrome.scripting.executeScript`): כותרת לפי `og:title` → `h1` → `document.title`, וגוף לפי `article` → `main` → `#content` → `body`, עם הסרה של `script/style/nav/header/footer/form/...`.

### סכימת IndexedDB (`article-saver-db`, version 1)

- **lists** — `{ id, name, createdAt }` (אינדקס `name`)
- **articles** — `{ id, listId, title, content, url, savedAt, summary?, notes?, chat? }` (אינדקסים `listId`, `savedAt`)
  - `summary` — מחרוזת Markdown; `notes` — HTML של הערות; `chat` — מערך `[{ role: "user"\|"assistant", text }]`
- **settings** — `{ key, value }`; מפתחות: `activeListId`, `geminiApiKey`, `geminiModel`

### פריסת החלונית (JS — `sidepanel.js`, IIFE)

- `loadAll()` — טוען רשימות+מאמרים+הגדרות, קובע רשימה פעילה, מעדכן `activeListId` ב-settings, מרנדר.
- `renderLists()` / `renderArticleRow()` — בנויים ב-DOM (ללא template).
- `showDetail(a)` — בונה דינמית (לכל מאמר): כותרת, URL, מטא (`meta.dataset.base`), `.detail-mid` עם **תקציר AI** (+`צור מחדש`), **הערות** (עורך `contentEditable` + toolbar מקישורים ל-`document.execCommand`), **שיחה** (`renderChat`/`sendChat`), וטקסט מלא (`contentEditable`, נשמר ב-`blur`).
- `applyActiveRow()` — הדגשת `.article-item.active` לפי `activeArticleId`.
- `fitDetailToLists()` — במצב מלא מגדיר גובה `.detailBody` לגובה עמודת הרשימות; רץ על resize.
- מרנדר מחדש גם ב-`visibilitychange` (כשהחלונית נכנסת לחזית).

### פריסת CSS

- בסיס: RTL, כרטיסים, כפתורים, `.rich-text`, `.chat-*`, `.detail-*`; מצב פעיל של מאמר; placeholder על ערכים ריקים.
- **מצב מלא** (`@media (min-width:760px)` + `body.full`): grid עם 3 עמודות `1fr`; `#detailBody` רשת של `1fr 1fr` עם `grid-template-rows: auto auto auto 1fr`; `.detail-mid` עמודה גמישה (`flex`), הצ'אט `flex: 1 1 auto` (מתארך עד סוף העמוד), הטקסט `sticky` עם גלילה פנימית.

## פיתוח

- אין build — טוענים את התיקייה כ-"load unpacked" ומרעננים.
- ספריות מקומיות ב-`lib/` (אין CDN, הפרטיות נשמרת לחלוטין מקומית).
- בדיקות ידניות ל-Excel מתבצעות עם פתיחה ב-LibreOffice/Excel; תהליך האימות הפנימי שנמצא ב-`excel-export.js` מבטיח פתיחה תקינה גם כשיש עוגת XML עדינה.
