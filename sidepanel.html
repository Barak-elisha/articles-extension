How to get an API key
  1. Open Google AI Studio and sign in with your Google account.
  2. Copy an existing key, or choose Create API key and select or create a project.
  3. Paste the key below and choose Save key. Use Refresh models to see available models.

Your key is saved on this device. Refreshing models sends the key to Google. Clear and save to remove it.

API usage and costs

AI summaries and chat consume your Google API quota. If billing is enabled, charges may apply depending on your model and plan. Monitor usage in Google AI Studio.
